# Agently Vue

基于 Vue 3 + Vite 构建的多 Agent 智能问答前端界面，对接 [Agent-Hwan](http://localhost:8088) 后端服务，支持流式对话、多 Agent 切换、自动意图路由等功能。

## 功能特性

| 功能 | 说明 |
|------|------|
| **流式对话** | 通过 SSE 实时接收 AI 回答，逐字渲染，带打字光标动画 |
| **@ Agent 选择** | 点击输入框上方的 `@` 按钮，弹出 Agent 选择面板 |
| **自动路由** | 开启后系统智能分析意图，自动分发到最合适的 Agent |
| **手动切换 Agent** | 在 Agent 面板中选择指定 Agent，关闭自动路由后生效 |
| **路由标签** | 每条 AI 回复顶部显示被路由到哪个 Agent 及路由原因 |
| **Markdown 渲染** | AI 回答支持代码块、表格、列表、加粗等 Markdown 格式 |
| **停止生成** | 流式输出过程中，发送按钮变为停止按钮，可随时中断 |
| **工具侧边栏** | 右上角工具图标，查看当前 Agent 拥有的工具列表 |
| **清空历史** | 右上角垃圾桶图标，调用后端接口清空当前 Agent 的对话历史 |
| **历史记录恢复** | 页面加载时自动拉取后端历史记录并渲染 |
| **快捷建议** | 无消息时展示示例问题，点击即可填入输入框 |
| **Toast 通知** | 切换 Agent、清空历史等操作的轻量反馈提示 |

## 内置 Agent

| Agent ID | 名称 | 能力 |
|----------|------|------|
| `general` | 🛠️ 通用工具助手 | 天气查询、IP 查询、翻译、二维码生成、文本处理、短链接生成 |
| `gold_analysis` | 📊 黄金分析助手 | 专业黄金市场分析、行情查询、投资参考 |

> `intention_router` 是系统级路由 Agent，不对外暴露，不可手动切换。

## 快速开始

### 前置条件

- Node.js >= 18
- 后端服务 [Agent-Hwan](http://localhost:8088) 已在本地运行

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

浏览器访问 **http://localhost:5173**

> Vite 已配置 `/api` 路径代理到 `http://localhost:8088`，无需额外处理跨域。

### 构建生产版本

```bash
npm run build
```

产物输出到 `dist/` 目录。

## 后端接口说明

前端通过 [`src/api.js`](src/api.js) 封装了以下接口：

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/chat` | 发送消息，SSE 流式接收回答 |
| `GET` | `/api/agents` | 获取可用 Agent 列表 |
| `POST` | `/api/switch` | 切换当前激活的 Agent |
| `GET` | `/api/history` | 获取当前 Agent 的对话历史 |
| `DELETE` | `/api/history` | 清空当前 Agent 的对话历史 |
| `GET` | `/api/tools` | 获取当前 Agent 的工具列表 |

完整接口文档见 [`API_DOC.yaml`](API_DOC.yaml)。

## 技术栈

- **Vue 3** (Composition API)
- **Vite 5**
- **marked** — Markdown 解析渲染
- 原生 `fetch` + `ReadableStream` — SSE 流式处理
- 纯 CSS 变量设计系统（无 UI 框架依赖）
